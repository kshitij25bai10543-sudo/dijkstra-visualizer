What is Dijkstra's algorithm?

Dijkstra's algorithm finds the shortest path from one source node to every other node in a weighted graph. It always settles the closest unvisited node next, which makes it a greedy algorithm. It was published by Edsger W. Dijkstra in 1959.

GPS and maps

Finds the fastest route between two places on a road network.

Network routing

Protocols such as OSPF and IS-IS use it to route internet traffic.

Transport and games

Plans transit journeys and moves game characters across maps.

Dijkstra's algorithm does not work correctly with negative edge weights. It requires every weight to be non-negative.

How the algorithm works

Select a step to see it on the graph.

Pseudocode

DIJKSTRA(Graph, Source):
    distance[source] = 0
    for every vertex:
        distance[vertex] = infinity
        previous[vertex] = null
    while unvisited vertices remain:
        u = vertex with minimum distance
        mark u as visited
        for each neighbor v of u:
            newDistance = distance[u] + weight(u, v)
            if newDistance < distance[v]:
                distance[v] = newDistance
                previous[v] = u
    return distance and previous

Complexity

O(V²)

Time with the simple array implementation: scan all vertices to find the minimum, V times.

O((V + E) log V)

Time with a priority queue (min-heap), which this project uses.

O(V + E)

Space for the adjacency list, distances, and predecessors.

V is the number of vertices (nodes). E is the number of edges (connections).
